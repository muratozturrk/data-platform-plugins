# apache-ranger – examples

- `deploy/` – `install.properties` (Admin, PostgreSQL, OpenSearch audit), Kubernetes manifests (schema-setup Job, Admin Deployment/Service, single usersync), ExternalSecret, usersync LDAP properties, local `docker-compose.yml` for tests
- `plugins/` – Trino (`access-control.properties`, `ranger-trino-security.xml`, `ranger-trino-audit.xml`), Kafka on Strimzi (custom authorizer CR + plugin XMLs + Dockerfile layer), Spark via Kyuubi AuthZ (`spark-defaults`, `ranger-spark-security.xml`)
- `policies/` – service and zone definitions (`trino-interactive`, `trino-etl`, `kafka-main`, `spark-sql`; zones linked to `platform-tags`; zone admin is the CI service user), baseline, `policy-manifest.yaml` (Institution with `services`, `owner`, `reviewBy` and `datasets`; RoleDefinition incl. `pii-reader` and `restricted-reader`; RoleAssignment at institution, domain, staging or dataset scope with optional `columns`, `topics`, `agreement`, `validity`, `assignmentType: eligible` + `eligibility`/`activation`, `request`, `reviewBy`; the shape of azure-style-rbac-abac.md), tag policies (zone tag mask with infotype masks via `PII` attribute `type`, `RESTRICTED` column mask and table-level deny guardrail), decision table
- `automation/` – `compile_policies.py` (manifest → Ranger JSON per service and zone with stable GUIDs and labels; writes only to `trino-etl` and Spark; shares only to `trino-interactive` with a row filter generated from the agreements; activated PII/Restricted Reader items in `{zone}-tag-mask`; per-zone break-glass allows; rejects user principals, human writes outside staging, foreign groups without an agreement, activations over PT8H and reader eligibilities over 3 months), `apply_policies.py` (plan/apply/drift via REST), `sync_tags_openmetadata.py`, `sync_groups_keycloak.py`, CI workflow
- `tests/` – offline compiler test (`test_compile_manifest.py`), decision-table test through Trino interactive and ETL (mask asserted by the mask type in `detail`), Kafka access test (OAUTHBEARER), audit-record assertion, propagation (revoke) test
- Lab checks before rollout: zone-scoped tag policies, `TAG._type` / `TAG.type` / `TAG.level` expression conditions, per-item `validitySchedules`, Spark database = `<catalog>_<schema>` mapping (trial: ranger-policy-compile, 2026-11-16)
