# Sources

## Books (rules paraphrased, chapters cited)
- Andy Kirk, *Data Visualisation: A Handbook for Data Driven Design*, 2nd ed. (2019), ch 9 Colour (HSL model, quantitative and categorical scales, functional decoration, accessibility).
- Nicholas Desbarats, *Practical Charts* (2023), ch 3 Color (palette types, grey, red/green, colour-blindness, too many colours, brand colours).
- Stephen Few, *Information Dashboard Design* (2006), ch 4 (visual perception, limits on hues).
