# Sources

- Mark Richards, Neal Ford. *Fundamentals of Software Architecture*, 2nd ed. O'Reilly, 2025. Chapter "Microkernel Architecture Style": core system + plug-in components; natural fit for product-based applications installed at customer sites. 1st ed. (2020) ch. 12 covers the same.
- Mark Richards. *Software Architecture Patterns*, 2nd ed. O'Reilly, 2022. Microkernel chapter.
- Real-world SPIs to model on: Apache Airflow providers, dbt adapters, Kafka Connect connector API, Singer taps/targets, Airbyte connector spec, Trino connector SPI.
- Python packaging entry points (PyPA) and Java `ServiceLoader` for discovery.
