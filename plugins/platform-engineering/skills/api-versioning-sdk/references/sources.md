# Sources

- Semantic Versioning 2.0.0. https://semver.org
- IETF RFC 8594, *The Sunset HTTP Header Field*; IETF draft *The Deprecation HTTP Header Field*.
- OpenAPI Specification; Protocol Buffers language guide (compatibility rules).
- Kubernetes API conventions and deprecation policy (apiVersion, served/storage versions, deprecation windows) as a reference model for manifest versioning.
- Camille Fournier, Ian Nowland. *Platform Engineering*, chapters on platform interfaces and migrations.
